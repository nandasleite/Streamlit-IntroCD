# Análise Exploratória dos Dados de Missões Espaciais realizadas a partir de 1957

Este repositório contém o trabalho final desenvolvido para a disciplina de **Introdução à Ciência de Dados**. O projeto consiste em uma aplicação interativa criada com **Streamlit**, focada na Análise Exploratória dos Dados de Missões Espaciais realizadas a partir de 1957.



## 🚀 Sobre o Projeto

O objetivo principal desta aplicação é apresentar uma análise de dados de forma intuitiva, permitindo que o usuário interaja com os filtros e visualize insights diretamente pelo navegador.

O projeto inclui:
- **Análise Exploratória (EDA):** Processamento e limpeza de dados.
- **Visualização de Dados:** Gráficos interativos.
- **Interface Web:** Dashboard desenvolvido em Python.



## 📂 Estrutura do Repositório

* `app.py`: Arquivo principal que inicia a aplicação Streamlit.
* `page1.py`: Página complementar com análises específicas.
* `NotebookAnalise.ipynb`: Notebook Jupyter com o rascunho e a lógica da análise de dados.
* `data/`: Pasta contendo os datasets utilizados.
* `requirements.txt`: Lista de dependências necessárias para rodar o projeto.



## 🛠️ Tecnologias Utilizadas

Para o desenvolvimento deste projeto, foram utilizadas as seguintes ferramentas:

* [Python](https://www.python.org/) - Linguagem base.
* [Streamlit](https://streamlit.io/) - Criação da interface web.
* [Pandas](https://pandas.pydata.org/) - Manipulação e análise de dados.
* [Jupyter Notebook](https://jupyter.org/) - Prototipagem da análise.
